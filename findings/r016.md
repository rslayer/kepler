# r016 — lgbm_sl_metricw

**Author:** researcher

**Hypothesis:** Plain L2 weights every series-day equally, so high-volume noisy series (FOODS_3_120) dominate the fit. WRMSSE weights each series by dollar sales / sqrt(scale). Weighting training rows by dollar weight / scale (both computed strictly before each training origin) aligns the loss with the metric.

**What changed:** `src/features.py::asof_features` adds aux columns `aux_scale`, `aux_wdollar` (+ `Panel.price_matrix`); `src/model.py::LGBMBaseline.sample_weight` gains `METRIC_WEIGHTS`; `LGBMShortLagsMetricW` = r010 with `METRIC_WEIGHTS = True`.

**Result vs best (r010, 0.778984):** aggregate WRMSSE 0.779691 (+0.0007). Per fold: 1: -0.0008, 2: -0.0110, 3: +0.0076, 4: +0.0070. 13% of rows get zero weight (no dollar sales in the prior 28 days), weights range up to 14x.

**Verdict:** discard — the reweighting is too aggressive (heavy tails, many zero-weight rows); folds 3-4 get worse. A tempered version (sqrt of the weight, clipped) is a possible follow-up.
